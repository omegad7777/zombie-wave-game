# 🧟 Call of Undead: Blockade 3D

> **레트로 스타일 1인칭 3D 웨이브 서바이벌 좀비 슈팅 게임 (FPS)**  
> *콜 오브 듀티(Call of Duty) 명작 좀비 모드(Nacht der Untoten) 특유의 웨이브 시스템, 포인트 경제, 창문 바리케이트 수리, 잠긴 문 해금, 미스테리 박스를 웹 브라우저에서 순수 Three.js와 Web Audio API로 구현한 프로젝트입니다.*

---

## 🎮 게임 플레이 요약

- **장르**: 1인칭 3D 웨이브 서바이벌 슈팅 (Retro FPS)
- **기술 스택**: React 19, TypeScript, Three.js, Tailwind CSS v4, Web Audio API
- **의존성 제로 (Zero 404s)**: 외부 이미지나 사운드 파일 없이 **100% 인코드 프로시저럴 캔버스 텍스처** 및 **Web Audio API 오실레이터/노이즈 합성**으로 구동됩니다.

```
[ 웨이브(라운드) 시작 ] 
          ↓
[ 바리케이트를 뚫고 몰려오는 좀비 처치 & 포인트 획득 ] 
          ↓
[ 파손된 창문 수리 (+10pt) & 잠긴 문 해금 (맵 확장) ] 
          ↓
[ 벽 무기 구매 (샷건/소총) & 미스테리 박스 (레이건) ] 
          ↓
[ 다음 고난도 라운드 돌입 ]
```

## 🕹️ 조작법 (Controls)

| 키 / 입력 | 동작 |
|---|---|
| **화면 클릭** | 마우스 포인터 고정 (1인칭 시점 진입, PointerLock API) |
| **마우스 이동** | 시점 회전 및 조준 (Mouse Look) |
| **W, A, S, D** | 전후좌우 이동 |
| **Space** | 점프 |
| **Shift** | 전력 질주 (Sprint) |
| **마우스 좌클릭** | 무기 사격 (총구 화염, 반동 킥백, 자동화기 연속 발사) |
| **R** | 탄창 재장전 (Reload) |
| **1, 2 / 마우스 휠** | 소지 무기 스왑 |
| **E** | 상호작용 (잠긴 문 열기, 벽 무기/탄약 구매, 미스테리 박스 활성화 및 획득) |
| **F (또는 E 길게 누르기)** | 바리케이트 판자 수리 (망치질 연타) |
| **ESC** | 마우스 커서 잠금 해제 |

## 🌟 핵심 게임 시스템 및 메커니즘

### 1. 경제 & 포인트(Points) 시스템
- **타격 (Hit)**: 좀비 몸체 타격 시 `+10 PTS` (하얀색 'X' 힛마커 표시)
- **처치 (Kill)**: 일반 처치 시 `+60 PTS`
- **헤드샷 처치 (Headshot Kill)**: 머리 히트박스 명중 시 2.5배 데미지와 함께 `+100 PTS` (선명한 붉은색 'X' 힛마커 + 두개골 파열 사운드)
- **바리케이트 수리 (Repair)**: 나무 판자 1개 복구 시 `+10 PTS` (라운드당 최대 50 PTS 한도)

### 2. 무기 시스템 (Weapons & Viewmodel)
카메라 하단에 각 무기별 3D 파츠 조립 뷰모델이 부착되어 있으며, 걷기 밥빙(Bobbing), 사격 시 반동 킥백, 총구 섬광 조명, 재장전 기울임 모션이 적용되어 있습니다.

| 무기명 | 분류 | 데미지 | 연사/방식 | 장탄수 | 특징 |
|---|---|---|---|---|---|
| **M1911 Colt** | 권총 (Pistol) | 35 | 단발 (4.0/s) | 8 / 32 | 기본 지급 보조무기, 높은 정확도 |
| **Remington 870** | 산탄총 (Shotgun) | 224 (28×8펠릿) | 펌프액션 | 6 / 36 | 벽 무기 (1000pt). 근거리 파괴력, 펠릿 탄착군 산탄 |
| **AK-47** | 돌격소총 (Rifle) | 65 | 전자동 (9.0/s) | 30 / 120 | 벽 무기 (1200pt). 마우스 좌클릭 홀드로 빠른 연사 |
| **Ray Gun (원더 웨폰)** | 특수 화기 | 320 (+광역 폭발) | 반자동 (3.5/s) | 20 / 160 | 미스테리 박스 전용. 초록빛 플라즈마 탄환 & 3.8m 반경 스플래시 폭발 |

### 3. 잠긴 문 해금 & 맵 확장 (Rooms & Debris)
- **시작 벙커 (Spawn Room)**: 권총 시작, Remington 870 벽 무기, 2개의 창문 바리케이트.
- **안뜰 잔해 제거 (Clear Debris, 750 PTS)**: 남쪽 바리케이트 잔해를 치우고 야외 안뜰(Courtyard) 오픈. 안뜰 중앙에 **미스테리 박스** 위치.
- **무기고 철문 해금 (Armory Gate, 1000 PTS)**: 동쪽 방벽을 열고 무기고 오픈. **AK-47 벽 무기** 구매 가능.

### 4. 미스테리 박스 (Mystery Box - 950 PTS)
- 상자 근처에서 `E` 키를 누르면 상자 뚜껑이 열리며 하늘로 푸른빛 빔이 솟구칩니다.
- 기괴한 오르골 징글 사운드와 함께 상자 위에서 3D 무기가 빠르게 회전합니다.
- 회전이 멈추면 결정된 무기(Ray Gun 등)가 공중에 떠오르며, 다시 `E` 키를 눌러 획득할 수 있습니다.

### 5. 바리케이트 & 좀비 침투 메커니즘
- 외벽 창문마다 5개의 나무 판자가 못 박혀 있습니다.
- 방 밖에서 스폰된 좀비는 창문으로 다가와 판자를 하나씩 뜯어냅니다 (판자 부서지는 소리와 함께 물리적으로 판자 소멸).
- 판자가 모두 제거되면 좀비가 창틀을 뛰어넘어(Vault) 실내로 진입합니다.
- 플레이어는 창문에서 `F` 키를 유지하여 판자를 다시 덧댈 수 있습니다.

### 6. 다관절 3D 좀비 AI & 라운드(Wave) 스케일링
- 몸통, 머리(헤드샷 부위), 양팔, 양다리, 붉고 노랗게 발광하는 눈으로 구성된 3D 다관절 모델.
- 걷기 시 팔다리 스윙 애니메이션, 근접 시 할퀴기 공격 애니메이션, 사망 시 뒤로 쓰러지는 쓰러짐 연출.
- 라운드가 올라갈수록 좀비 스폰 수, 체력, 이동 속도(느린 보행 좀비 $\rightarrow$ 전력 질주 러너)가 점진적으로 강화됩니다.
- 플레이어 체력은 100이며 좀비 근접 공격 시 35 데미지를 입습니다. 4초간 공격받지 않으면 자연 회복됩니다.

## 📁 소스 코드 구조 분석

```
├── index.html                   # HTML 진입점, Google Fonts (Nosifer, Teko, Chakra Petch)
├── metadata.json                # 앱 메타데이터 및 퍼미션 설정
├── package.json                 # React 19, Three.js, Lucide-React 등 의존성 정의
├── vite.config.ts               # Vite 설정 및 Tailwind CSS 플러그인
└── src/
    ├── main.tsx                 # React 루트 렌더러
    ├── index.css                # Tailwind CSS v4 스타일링
    ├── App.tsx                  # 3D 캔버스 컨테이너 및 엔진 생명주기 관리
    │
    ├── components/
    │   └── HUD.tsx              # CoD 좀비 정통 HUD 오버레이
    │                            # - 붉은색 분필 라운드 카운터
    │                            # - 체력 게이지 & 포인트 디스플레이
    │                            # - 무기 정보 & 잔여 탄약수
    │                            # - 동적 십자선 & 힛마커 (White/Red X)
    │                            # - 상호작용 안내 배너 (예: [E] 잔해 제거 [750 PTS])
    │                            # - 피격 시 붉은 비넷(Vignette) 및 사망 게임오버 통계 화면
    │
    └── game/
        ├── types.ts             # 무기 스펙, 인벤토리, 바리케이트, 문, 통계 타입 정의
        │
        ├── audio.ts             # Web Audio API 100% 프로시저럴 사운드 합성기
        │                        # - 4종 무기 고유 발사음 및 펌프액션/플라즈마 폭발음
        │                        # - CoD 시그니처 힛마커 '팅' 틱 사운드 & 헤드샷 크런치
        │                        # - 바리케이트 목재 파손/수리 망치음
        │                        # - 미스테리 박스 회전 징글, 라운드 시작 혼/종료 팡파르
        │
        ├── textures.ts          # HTML5 Canvas 기반 동적 텍스처 생성기
        │                        # - 콘크리트 석조 벽돌 텍스처 (Stone Brick)
        │                        # - 오염된 바닥 타일 텍스처 (Concrete Tile Grid)
        │                        # - 나뭇결과 못이 박힌 판자 텍스처 (Wood Plank)
        │                        # - 벽 무기 분필 윤곽선 텍스처 (Chalk Weapon Outline)
        │                        # - 미스테리 박스 룬/물음표 텍스처 (Mystery Box '? ?')
        │
        ├── weapons.ts           # 무기 세부 수치(데미지, 탄약, 연사속도) 및 3D 뷰모델 빌더
        │                        # - M1911, Remington 870, AK-47, Ray Gun 모델 조립
        │
        ├── map.ts               # 벙커 레벨 디자인 및 충돌체(AABB Colliders) 빌더
        │                        # - 시작 벙커, 안뜰, 무기고 3개 구역 3D 공간
        │                        # - 개폐식 장애물 문, 바리케이트 창문 6개소
        │                        # - 벽 무기 구매 지점 및 미스테리 박스 배치
        │
        ├── zombie.ts            # 다관절 3D 좀비 모델 생성, 히트박스 분리, 능력치 스케일링
        │
        └── engine.ts            # Three.js 코어 게임 엔진
                                 # - WebGL 렌더러, ACES 필믹 톤매핑, Studio Environment 반사
                                 # - PointerLock 시점 회전 및 AABB 2D 충돌 판정 플레이어 물리
                                 # - 레이캐스트 사격 판정 (산탄 펠릿, 헤드샷 구분, 레이건 스플래시)
                                 # - 웨이브 라운드 관리 및 좀비 스폰/침투 AI 루프
                                 # - 파티클 시스템 (혈흔 파편, 폭발 파티클)
```

## 🛠️ 로컬 실행 및 빌드 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속 후 화면을 클릭하면 즉시 1인칭 모드로 진입합니다.

### 3. 프로덕션 빌드
```bash
npm run build
```
